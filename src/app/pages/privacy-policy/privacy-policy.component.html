This simple CRM prototype enables users to enter and manage various personal details, including but not limited to:

  • Any other details provided by the user

This system is intended solely for development and demonstration purposes, not for live or production use. Real or sensitive customer data should only be entered if anonymized or with explicit consent. All collected data is used exclusively for functionality testing. Data Security

All data is stored in Firebase, a cloud platform provided by Google. Data transmission and storage are handled via Firebase’s default security features. The developer of this prototype does not implement additional data protection measures beyond those provided by Firebase.

Data Collected from Website Visits

When you visit this website, the following data may be automatically collected and stored in log files by the hosting provider HOSTINGER:

  • Visit Timestamp: The time of the visit.

  • IP Address: The originating IP address.

  • Request: The page or resource accessed.

  • Device Info: Details about the device used.

  • Location: The country derived from the IP address.

  • Data Size: The size of the request/response in bytes.

  • Response Time: Server’s response duration.

This data is collected for the purpose of maintaining the security and performance of the website, analyzing trends, and improving the user experience. The collected data will not be used for marketing purposes and will not be shared with third parties. It is stored securely and only retained for as long as necessary for these purposes.

Preference Storage

This website stores your theme preference (dark/light mode) using your browser’s local storage. This data is not transmitted to a server and does not use cookies. The stored preference allows the website to remember your selected theme upon revisits.
